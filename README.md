# Surf Del Mar Hotel Website

## How to Use

### 1. Replace Images
Put your photos in the `assets/images/` folder using these exact file names:

| File Name        | What to put there                        |
|------------------|------------------------------------------|
| hero-bg.jpg      | Main hero/hotel exterior photo           |
| signboard.jpg    | Hotel name board photo                   |
| room1.jpg        | Standard room photo                      |
| room2.jpg        | Family room photo                        |
| room3.jpg        | Deluxe room photo                        |
| surf.jpg         | Surf lessons / beach photo               |
| exterior.jpg     | Hotel exterior (about section)           |
| courtyard.jpg    | Hotel courtyard/garden photo             |
| gallery1.jpg     | Gallery photo 1                          |
| gallery2.jpg     | Gallery photo 2                          |
| gallery3.jpg     | Gallery photo 3                          |
| gallery4.jpg     | Gallery photo 4                          |
| gallery5.jpg     | Gallery photo 5                          |
| gallery6.jpg     | Gallery photo 6                          |
| surfer.png       | Surfer PNG (transparent background)      |

### 2. Update Links
In `index.html`, update:
- Booking.com link → your real Booking.com hotel URL
- WhatsApp number → already set to 0753758832

### 3. Upload to Hosting
Upload the entire `surf-del-mar/` folder to Register.lk hosting.

## Folder Structure
```
surf-del-mar/
├── index.html       ← Main homepage
├── style.css        ← All styles
├── script.js        ← All JavaScript
├── assets/
│   └── images/      ← Put ALL your photos here
└── README.md        ← This file
```
